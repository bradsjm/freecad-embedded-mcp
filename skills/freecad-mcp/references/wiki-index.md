## Scope exclusions

The MCP tools do not expose a CAM toolpath generator or a TechDraw workflow. `export` covers STL, STEP, 3MF, and FCStd output; other import/export routes may be reached indirectly through `run_script`, but they are not direct MCP capabilities. Addon installation through the Addon Manager, if required, is an external/user-side boundary unless a safe non-interactive API has been verified in the running installation.
